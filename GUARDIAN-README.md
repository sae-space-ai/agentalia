# 🛡️ Agentalia Guardian - Agente Soberano de Cumplimiento Normativo UE

## Descripción

**Agentalia Guardian** es un agente soberano especializado en cumplimiento normativo de la Unión Europea, diseñado para ayudar a empresas y entidades a cumplir con el **AI Act** y el **RGPD (GDPR)**, evitando sanciones millonarias.

### Características Principales

- ✅ **Monitoreo Continuo 24/7** de cumplimiento normativo
- ✅ **Auditorías Automatizadas** de sistemas de IA y protección de datos
- ✅ **Alertas Tempranas** de posibles incumplimientos y sanciones
- ✅ **Generación de Informes** de conformidad regulatoria
- ✅ **Evaluación de Riesgos** y recomendaciones de mitigación
- ✅ **Gestión de Certificaciones** AI Act y RGPD

---

## 🎯 Normativas Cubiertas

### 1. AI Act (Regulación de Inteligencia Artificial)

**Sanciones por incumplimiento:**
- Hasta **35 millones de euros** o **7% del volumen de negocios mundial**

**Funcionalidades:**
- Clasificación automática de sistemas de IA por nivel de riesgo
- Evaluación de conformidad para sistemas de alto riesgo
- Documentación técnica y registro de actividades
- Verificación de marcado CE
- Monitoreo post-mercado
- Supervisión humana para sistemas críticos

### 2. RGPD (Reglamento General de Protección de Datos)

**Sanciones por incumplimiento:**
- Hasta **20 millones de euros** o **4% del volumen de negocios mundial**

**Funcionalidades:**
- Registro de actividades de tratamiento
- Evaluaciones de impacto (DPIA)
- Gestión de consentimiento válido
- Procedimientos de ejercicio de derechos ARCO
- Notificación de brechas de seguridad (72h)
- Designación y soporte para DPO
- Medidas de seguridad técnicas y organizativas

## 🛠️ Instalación y Uso

### Requisitos
- Node.js 18+
- npm o yarn
- Navegador moderno

### Instalación

```bash
# Clonar repositorio
git clone https://github.com/tu-usuario/agentalia.git
cd agentalia

# Instalar dependencias
npm install

# Copiar variables de entorno
cp .env.example .env.local

# Ejecutar en modo desarrollo
npm run dev

# Compilar para producción
npm run build
```

### Acceso al Dashboard de Cumplimiento

1. Iniciar la aplicación: `npm run dev`
2. Navegar a: `http://localhost:5173/compliance`
3. O usar el **Command Palette** (⌘K) y buscar "Cumplimiento"
